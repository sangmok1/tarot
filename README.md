# LUNA TAROT · 달빛 타로

타로 마스터가 카드를 섞고 펼쳐주면, 마음속 질문을 떠올리며 카드를 뽑아 해석을 보는 웹 페이지입니다. 빌드 없이 `index.html`만 열면 동작하며 모바일 화면을 지원합니다.

- 주제: 연애·인연(3장) / 오늘의 메시지(1장) / 고민·운세(3장)
- 질문을 입력하면 내용에 맞춰 주제를 자동 선택
- 리플 셔플 → 부채꼴 펼치기 → 카드 선택 → 3D 뒤집기 → 해석
- 메이저 아르카나 22장, 정/역방향 해석

## 실행

`index.html`을 브라우저로 열면 됩니다. 배포 시 `index.html`과 `cards/` 폴더를 함께 올리세요.

## 카드 이미지

`cards/`의 이미지는 1909년 Rider-Waite-Smith 타로(일러스트 Pamela Colman Smith)로, 퍼블릭 도메인이며 Wikimedia Commons에서 가져왔습니다.
